# З10. Дашборд бронирований

Источник всех виджетов — база `booking_dw` в ClickHouse. DuckDB к Metabase
не подключается. Дашборд содержит три SQL-виджета:

| Виджет | SQL | Источник |
|---|---|---|
| Состоявшиеся бронирования | `completed_bookings.sql` | Детальная `fact_booking`, условие `Check-Out`, как в эталоне |
| Бронирования по месяцам и отелям | `monthly_bookings.sql` | Дневная сводка З09, суммирование по месяцу и отелю |
| Топ-10 сегментов и каналов | `top_channels.sql` | Детальная `fact_booking`, условие `Check-Out` |

Один общий фильтр «Период заезда» связан с `dim_date.full_date` во всех трёх
запросах. Без фильтра показывается весь доступный период. Граница периода
относится к дате заезда, а не к дате последнего статуса.

## Воспроизведение

Из корня проекта после загрузки DuckDB и ClickHouse:

```powershell
docker compose up -d metabase
Invoke-RestMethod http://localhost:3000/api/health
python scripts/setup_dashboard.py
```

Дождитесь `status=ok` перед запуском скрипта. При первом запуске Metabase скрипт
создаёт локального администратора со случайным паролем и сохраняет логин/пароль
в `data/metabase_local.json`. Этот файл не попадает в Git. Если Metabase уже
настроен вручную, передайте учётные данные через переменные среды
`METABASE_USER` и `METABASE_PASSWORD`.

Скрипт создаёт подключение ClickHouse, три вопроса и дашборд либо обновляет
одноимённые объекты при повторе. Адрес дашборда выводится в консоль и сохраняется
в `data/metabase_dashboard.json`. Откройте его в браузере и войдите с локальными
учётными данными. Общедоступные ссылки не включаются.

Docker Compose использует имена контейнеров своего проекта и монтирует только
драйвер ClickHouse. Именованные тома сохраняют настройки Metabase и данные
ClickHouse. Порты — 3000 и 8123; другой стенд на этих портах должен быть остановлен.

Фактические проверки всех трёх запросов без фильтра и за сентябрь 2016 года
сохранены в `z10_checks.txt`. Скриншоты: `z10_dashboard.png` и
`z10_dashboard_september.png`. Скрипт настройки также проверен повторным запуском:
идентификаторы трёх вопросов и дашборда сохраняются, дубли не создаются.
