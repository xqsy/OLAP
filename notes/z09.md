# З09. Сводка для графика сезонности

Будущий виджет — количество состоявшихся бронирований по месяцам заезда и отелям,
первый бизнес-вопрос паспорта.

Одна строка сводки `agg_booking_daily` = один день заезда × один отель.
`completed_booking_count` — число бронирований со статусом `Check-Out`.
Для месячного графика складываем дневные значения, сохраняя группировку по отелю.
Дневное зерно позволяет фильтровать произвольный диапазон дат без включения
дней за его границами.

DDL и пересчёт: `sql/aggregate_booking_daily.sql`. После каждой успешной загрузки
деталей `etl/load_clickhouse.py` автоматически очищает сводку и заполняет её заново.
Повторный запуск не добавляет значения к прежним итогам.

`sql/check_aggregate.sql` проверяет все сочетания дня и отеля, включая лишние
и отсутствующие группы. Загрузчик дополнительно сравнивает сумму за весь период
и за контрольный сентябрь 2016 года с подсчётом по деталям при тех же условиях.
Фактические результаты двух загрузок — `etl/lab09_runs.txt`.

Эталон `sql/canonical_metric.sql` продолжает считать главную метрику
по `fact_booking`, независимо от сводки.
