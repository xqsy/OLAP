# З10. Дашборд Metabase

**Практика:** [[P10_дашборд_metabase|P10]]  
**Вход:** ClickHouse с вашими таблицами ([[З07_загрузка_clickhouse|З07]], при наличии сводка из [[З09_mv_витрина|З09]])

---

## Зачем

Собрать **дашборд** — экран с карточками и графиками — поверх ClickHouse.  
Metabase здесь только рисует. Источник правды — таблицы в ClickHouse, не файл DuckDB.

## Что сделать

1. Подключить Metabase к ClickHouse.
2. Сделать дашборд минимум из трёх виджетов (карточка или график).
3. Добавить фильтр (период или регион) и хотя бы один виджет с текстом SQL.

---

## Ход работы

### 1. Подключение

В Metabase добавьте базу ClickHouse (драйвер — см. README `Стенд`).  
Если на паре драйвер капризничает — запросы покажите через client ClickHouse, драйвер догоните. На сдаче источник всё равно должен быть ClickHouse.

### 2. Дашборд

Три виджета лучше привязать к вопросам из паспорта.  
Один фильтр на весь дашборд: например «период» или «регион».

### 3. Виджет с текстом SQL

Хотя бы одна карточка или график — не только клики в конструкторе, а вставленный SQL.  
Удобно сразу поставить эталон главной метрики из `canonical_metric.sql`.

SQL всех важных виджетов скопируйте в `dashboards/` в репозитории: текст важнее красивого скрина.
