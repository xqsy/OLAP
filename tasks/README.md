# Практические задания · один проект на семестр

Вы делаете **одну аналитическую витрину** — набор таблиц, по которым удобно считать отчёты — от исходных файлов до дашборда.  
Каждая задача (З01…З12) — отдельный шаг. Тему проекта и главное число (метрику) по ходу не меняем, только уточняем описание.

Связь с практиками: **З01↔P01 … З12↔P12**. После З12 — защита на [[P13_polish_защита|P13]].  
Чеклист зачёта: [[чеклист_зачёта_канон|чеклист зачёта]].

## Словарь

| Говорим | Имеем в виду |
|---------|----------------|
| **Сырьё (`data/raw/`)** | Исходные CSV/Parquet «как пришли» |
| **Витрина** | Таблицы для анализа (справочники + события), не Excel-файл как «база» |
| **Паспорт** | Короткая анкета: что считаем, какие таблицы, какое главное число |
| **Зерно строки** | Что означает одна строка в таблице событий. Пример: «одна строка = одна позиция в чеке» |
| **Таблица факта** | События, продажи, обращения — здесь лежат числа |
| **Измерение (справочник)** | Магазины, товары, даты, клиенты |
| **Мера** | Число, которое суммируем или считаем (оборот, количество) |
| **Главная метрика / эталонный SQL** | Одно число проекта и один SQL-файл; с ним потом сверяют карточку на дашборде |
| **`cut.md`** | Список того, что сознательно не делаем, и чем это грозит отчётам |
| **DDL** | SQL, который создаёт таблицы |
| **Скрипт загрузки** | Программа или SQL: взял сырьё → проверил → положил в витрину |
| **SCD2** | История справочника: атрибут изменился — старая версия строки осталась, появилась новая |
| **Сводная таблица / MV** | Уже посчитанные суммы (например «день + магазин → оборот»), чтобы дашборд не суммировал все продажи каждый раз |
| **Виджет** | Карточка или график на дашборде |
| **ClickHouse** | Серверная БД для анализа; на зачёте обязательна |

Подробности — внутри каждой задачи, там где термин встречается.
